# Plugin publishing standard

Every plugin in this marketplace meets this standard. **Enforced by** says who checks it.

## Mandatory

| # | Requirement | Enforced by |
| --- | --- | --- |
| 1 | Folder at `plugins/<name>/`, registered in `.claude-plugin/marketplace.json` with `source: ./plugins/<name>` | CI |
| 2 | Name is lowercase-hyphenated, 64 characters or fewer, and the same in folder, manifest and marketplace entry | CI |
| 3 | `.claude-plugin/plugin.json` with name, semver version, description, and author name and email | CI |
| 4 | Version bumped on every change (patch, minor or major) | CI (PRs) |
| 5 | At least one skill at `skills/<name>/SKILL.md`, frontmatter `name` matching the folder | CI |
| 6 | Skill description of 50 to 1,024 characters that says when to use it and when not to | CI and Copilot review |
| 7 | `evals/evals.yaml` with at least 10 cases, including trigger cases that should and should not fire | CI (count) and Copilot review (quality) |
| 8 | Evals pass | CI (once the eval runner is wired up) |
| 9 | `README.md` with owner, status, platforms and usage | CI (exists) and Copilot review (content) |
| 10 | A CODEOWNERS line for `/plugins/<name>/` | CI |
| 11 | No secrets, keys or tokens in any file | CI |
| 12 | Generated files up to date: `.cursor-plugin/`, `mcp.json`, `catalog.json` | CI |
| 13 | No duplicate of an existing skill or agent, or a stated reason why it is different | CI warning, Copilot review, human approval |
| 14 | Follows the [skill authoring standard](skill-authoring-standard.md) | Copilot review and human approval |

## Layout

```text
plugins/<name>/
├── .claude-plugin/plugin.json     # source of truth (Claude Code, VS Code, Copilot CLI)
├── .cursor-plugin/plugin.json     # GENERATED by scripts/sync_manifests.py
├── skills/<skill>/SKILL.md        # required; the most portable component
│   ├── steps/                     # ordered procedures
│   ├── references/                # rules, mappings, schemas (one copy each)
│   ├── templates/                 # output formats
│   └── scripts/                   # deterministic checks
├── agents/<agent>.md              # optional; keep thin
├── commands/<command>.md          # optional
├── hooks/hooks.json               # optional; least portable
├── .mcp.json                      # optional; source of truth for MCP servers
├── mcp.json                       # GENERATED copy for Cursor and Agent Plugins
├── evals/evals.yaml               # required; at least 10 cases
└── README.md                      # required
```

## Portability across IDEs

| Component | Claude Code | VS Code | Copilot CLI | Cursor | Guidance |
| --- | --- | --- | --- | --- | --- |
| Skills | Yes | Yes | Yes | Yes | Put the logic here |
| MCP servers | `.mcp.json` | Yes | `mcp.json` | `mcp.json` | Keep both files (one generated) |
| Agents | Yes | Yes | Yes | Yes | Keep thin; frontmatter and tools differ |
| Commands | Yes | Yes | Yes | Yes | Keep thin |
| Hooks | Yes | Partial | Yes | Yes | Avoid in shared plugins; behaviour differs |

## Not allowed

- A top-level `bin/` folder. Claude org sync rejects the plugin. Use `scripts/`.
- `hooks.json` at the plugin root. Use `hooks/hooks.json`.
- Hand-edited generated files.

## Versioning and lifecycle

- `0.x` means beta and `1.0.0` or later means stable. Promotion is a version bump, not a rename.
- To rename or retire a plugin, add it to the `renames` map in `.claude-plugin/marketplace.json` so existing installs follow it.
