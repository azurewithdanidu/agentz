# Lyric format

Use only the sections the user requested. These labels are defaults, not a
requirement to expand a fragment into a full song.

```text
Title: <original title>

[Verse 1]
<lyrics>

[Chorus]
<lyrics and central hook>

[Verse 2]
<lyrics that develop the story>

[Chorus]
<repeat or intentionally vary the hook>

[Bridge]
<new perspective or emotional turn>

[Final Chorus]
<closing hook>
```

For revisions, label the revised section and preserve required lines verbatim.
For alternatives, label each option. For feedback, identify the line, explain
the craft issue and suggest a replacement. Omit commentary when lyrics only
were requested. Never claim a file was saved unless it was actually written.
